# Security

Please do not post credentials or exploit details in public issues. Report security concerns to the repository owner through a private channel available on [their GitHub profile](https://github.com/Protagonist01).

Use generated production secrets, HTTPS/WSS, trusted proxy settings and private datastore access. The project has no formal security response SLA. See `docs/architecture.md` for current limits and `docs/audit.md` for the latest recorded checks.
